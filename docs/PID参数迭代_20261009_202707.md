## 本轮修改

只修改`config.h`四轮速度比例系数，保留PI结构。

| 参数 | 原值 | 试调值 |
|---|---:|---:|
| SPEED_KP_FL / kp_FL | 0.10 | 0.16 |
| SPEED_KP_FR / kp_FR | 0.10 | 0.16 |
| SPEED_KP_RL / kp_RL | 0.10 | 0.14 |
| SPEED_KP_RR / kp_RR | 0.10 | 0.14 |

四轮Ki仍0.001，Kd仍0，ff仍0。视觉Kp1=1.6、Kp2=0.012、Kd=0.3、上限240deg/s、固定前瞻55、IMU反馈0.08与安装符号均不改。速度150cm/s、500ms斜坡、K1/K2行为不改。

代码为增量式PID：`delta=Kp*(e0-e1)+Ki*e0+Kd*(e0-2e1+e2)`，随后累计输出。Kp提高会增强误差变化时的加速/减速响应。前轮从0.10到0.16：单次误差增加50cm/s，比例输出增量从5%变8%；误差减小或转负时，也会更快回收输出。并不是固定给前轮增加3%占空比。

后轮在回收差速时也滞后，因此小幅提高到0.14。保留Ki，避免本轮把瞬态响应与累计补偿同时改变；先不加D，避免放大编码器5ms计数量化噪声。

这些是待比较的试调值，不是从单次数据唯一辨识出来的最优参数；Kp提高也可能增加振荡或打滑。
