```
编码器每圈计数 = 1024
车轮每圈计数 = 1024 × 68/30 ≈ 2321.06667
每厘米计数 = 1024 × 68/30 ÷ 19.5 ≈ 119.02906 count/cm
轮速(cm/s) = Δenc / 119.02906 / (Δsamples × 0.005)
```

只回退解码模式而保留476.11624，会使速度/距离少算4倍，已同步修正。
上述规格值仍以68齿轮与车轮同轴并直接驱动30齿编码器齿轮为前提。
