## 3. 用户操作

1. 打开新版，进入左侧“05 快捷命令”。
2. 默认勾选“沿用 01 调参的发送地址”，目标 IP/端口跟随 01 页的**模块 IP/发送端口**，05 的地址输入框禁用。取消勾选可独立填写目标。
3. 新增条目，填写名称、格式、内容和备注。备注只保存在电脑，不加入报文。
4. 每行点击“发送”，只发送一次，不自动重发；无需先开启参数/日志/图像监听。
5. 文本选择 None/LF/CRLF；HEX、Binary 自动将行尾设为 None，并禁用行尾选项。大小端仅对 Binary 生效。
6. ↑/↓调整顺序；复制生成新条目 ID；删除移除该条目。可以删除全部条目，再新增。
7. 编辑后约0.6秒自动保存；“保存列表”立即保存。正常关闭时会保存仍在等待的编辑。
8. 导出时路径可留空，自动生成 JSON 并将路径填回输入框。导入必须提供路径；成功导入会替换列表，并先备份原列表。导入失败不替换。

“命令端口”是车端模块接收命令的端口，不是电脑的参数8081、日志8082或图像8083监听端口；实际车端端口应根据其配置确认。

## 4. 实际编码规则

| 格式 | 内容与实际报文 |
|---|---|
| UTF-8 | 将输入内容按 UTF-8 编码，之后按选项附加行尾 |
| GBK | 将输入内容按 GBK 编码；不能编码的字符会报错 |
| HEX | `AA 55 00 FF` 变成四个原始字节；支持字节间空格/换行，不支持 `0xAA` 写法 |
| JSON | 验证输入是合法 JSON，拒绝 NaN/Infinity，然后保留原输入文字并按 UTF-8 编码；可以附加行尾 |
| Binary | 输入字段 JSON 数组，按数组顺序、指定类型和大小端连续打包；不自动加入帧头、长度、命令码、校验或行尾 |

文本中的字面量 `\n` 不会自动展开；可以在多行输入框输入实际换行，或选择 LF 附加 `0A`、CRLF 附加 `0D 0A`。如果内容本身已有换行，附加选项会再追加一次。

Binary 内容示例：

```json
[{"type":"uint16","value":4660},{"type":"float32","value":0.5}]
```

little 的实际字节为 `34 12 00 00 00 3F`；big 为 `12 34 3F 00 00 00`。

支持类型：`uint8/int8/uint16/int16/uint32/int32/uint64/int64/float32/float64`。

拒绝空内容、非法十六进制、非法 JSON、未知字段类型、整数越界或整数类型收到小数，以及超过IPv4 UDP单包65507字节的报文。格式选择只负责编码，单片机仍需识别这些字节。

名称、备注、列表 ID、显示结果均不加入 UDP 包。成功发送在运行日志记录名称、目标、长度及最多48字节的十六进制预览；运行日志仍集中在01页。

## 5. 保存格式和持久化

`STORE/quick_commands.json` 是专用配置，与 `settings.json` 分开。

STORE 优先使用 `%LOCALAPPDATA%/McarWiFiMonitor`；无写权限时回退到程序旁 `McarWiFiMonitorData`，再尝试用户 Documents。若使用程序旁回退目录，更换版本文件夹时要导出/导入列表或迁移该文件。

```json
{
  "version": 1,
  "inherit_target": true,
  "target_ip": "127.0.0.1",
  "target_port": 6666,
  "commands": [
    {
      "id": "unique-string-id",
      "name": "查询状态（协议示例）",
      "format": "UTF-8",
      "content": "GET_STATE",
      "note": "示例：需要单片机另外实现此命令",
      "ending": "LF",
      "byte_order": "little"
    }
  ]
}
```

示例中的127.0.0.1是本机测试地址，GET_STATE只是协议示例，不是已实现的车端命令。

- `inherit_target=true` 时目标按当前01页更新；导入文件中的地址不会覆盖01页的地址。
- 列表为空合法；导入重复/空 ID 会生成独立新 ID，避免控件冲突。
- 导入验证配置结构；允许保存尚未写完或暂时无效的内容，实际发送时再验证编码。
- 写入临时文件后原子替换目标，配置使用UTF-8明文JSON。
- 导入前备份为 `STORE/quick_commands_before_import_日期时间.json`。
- 损坏配置加载失败时原文件保留，不会因自动保存或正常退出被默认列表覆盖；手动保存列表或成功导入后恢复自动保存。
- 每行发送结果仅属于本次会话，不保存为“已执行”状态。
